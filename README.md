# Task Manager
[![CI](https://github.com/konstmalinin-maker/task-manager/actions/workflows/ci.yml/badge.svg)](https://github.com/konstmalinin-maker/task-manager/actions/workflows/ci.yml)
[![Build Status](https://img.shields.io/badge/build-passing-brightgreen)]()
Краткое описание проекта: консольный менеджер задач для учебных целей.
## Стек технологий
- Python 3.11 — используется для разработки CLI и тестирования
- pytest
## Установка
git clone git@github.com:username/task-manager.git
cd task-manager
python -m venv venv
source venv/bin/activate # Linux/macOS
pip install -r requirements.txt
## Использование
python src/main.py --help
## Структура проекта
src/ — исходный код
tests/ — тесты
docs/ — документация
