Task Manager

Учебный проект по программной инженерии.

О проекте

Task Manager — консольное приложение для управления задачами, разработанное на Python.

Возможности

Команда add демонстрирует добавление задачи, а команда list — просмотр списка задач. Функции пока реализованы в виде заглушек.

Технологии

Python 3.11, Git, GitHub Actions, pytest, Ruff.

Запуск

python src/main.py --help
